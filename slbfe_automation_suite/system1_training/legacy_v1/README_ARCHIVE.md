# legacy_v1 — archived first version

These files are the **v1** implementation (generic "any Training record"
checker with `people.csv`, session-state login and CSV reports).

They are kept only for reference. The active system is **v2** in the parent
folder: `../slbfe_training_checker.py`, which specifically verifies
**Pre Departure Training**, saves highlighted proof screenshots, and uses
`progress.json` for resume/skip behaviour. Do not run the two versions against
the same output folder.
